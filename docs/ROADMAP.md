# 实施路线图

本路线图以“生成稿与原章的事实、结构与写法都可量化比较”为完成目标。章节数量只用于控制成本；质量门槛不因样本少而降低。

## 阶段 0：清理边界与版本失效机制

**目标：** 让旧产物不能伪装成新规则下的合格数据。

- 为标注、连续性、图谱、模板、风格与 Skill 加入模式/提取器/质量策略/来源哈希版本。
- 检测到版本不匹配时，归档旧下游产物并要求重建。
- 禁用或拆分仍会读取 `original_story_state` 的旧正文重建入口，确保受控扩写只从图谱取事实。

**完成定义：** 同一语料在规则变更后不会静默复用旧标注；运行日志明确指出失效原因。

## 阶段 1：高密度语义标注与图谱修复

**目标：** 让图谱真的能解释原章。

- 窗口级质量门控和针对缺口的再标注。
- 稳定关系与事件交互分离；角色约束下的实体候选合并。
- 因果边聚合，并建立跨章状态/目标/物品/秘密延续链。
- 基于空间动作修复地点状态。
- 建立“线索候选—后文检索—回收确认”的闭环伏笔线程。

**完成定义：** 随机抽查 5 章，人工可由每个图谱结论回到原文证据；不存在明显错位的人物关系、地点状态或伪伏笔。

## 阶段 2：场景级风格蒸馏

**目标：** 将“作者文风”变为可执行、可证伪的约束。

- 扩充段落标注，获得叙述方式、节奏、对话、心理、描写、信息揭示、转场与钩子数据。
- 按场景角色而非全书平均值构建 `scene_style_program`。
- 导入同题材对照作者语料，计算区分度，淘汰泛化规则。
- 输出带支持样本和适用条件的风格卡。

**完成定义：** 风格卡能解释留出章节的场景差异，且目标作者与同题材对照作者可被稳定区分。

## 阶段 3：候选生成、校验与错误归因

**目标：** 让生成质量通过选择和反馈逐步提升，而不是盲目重试。

- 单段生成多个候选；每个候选附带局部图谱补丁。
- 硬性事实、状态、时间空间、因果、伏笔、重复风险先过滤。
- 由场景风格评分器和作者风格判别器重排。
- 留出 5 章做回归：原文只给评测器；报告定位到标注、图谱、程序、正文或风格层。

**完成定义：** 相比“仅图谱 + 单候选”的基线，候选重排在事实通过率和风格盲评上有可记录提升，且不提高复写风险。

## 阶段 4：本地 LoRA/SFT 实验

**目标：** 验证参数适配是否能减少通用 AI 腔并提高场景风格稳定性。

- 建立版本化训练集：`局部图谱 + 段落程序 + 风格程序 -> 原文段落`。
- 按作品或连续章节划分训练/验证/盲测，杜绝段落泄漏。
- 用小规模 LoRA/SFT 训练基线，比较“无适配器”和“适配器”在同一评测上的差异。
- 保存基础模型版本、LoRA 参数、数据版本、随机种子、评测报告。

**完成定义：** LoRA 在留出集上提升风格指标且不降低事实一致性、不增加长串重复。

## 阶段 5：DPO 与 Skill 发布

**目标：** 用可靠偏好对优化候选选择偏好，并形成可复现交付物。

- 由通过事实校验的候选构造偏好对；人工抽检与风格评分共同决定 `chosen/rejected`。
- 在 SFT LoRA 上做小步 DPO，对比是否发生风格奖励黑客或复写增加。
- 打包图谱模式、风格程序、判别器、可选 LoRA、模型配置要求与评测基线。

**完成定义：** `<作者标识>_skill/` 可在新环境复现同类生成流程，并带有数据/模型/评测版本与已知限制说明。

## 不应跳过的门槛

- 没有闭环伏笔验证，不进入风格训练。
- 没有同题材对照作者，不宣称已提取“作者独有文风”。
- 没有留出章节和防复写检测，不训练 DPO。
- 任何硬性图谱矛盾都不能用“文笔好”抵消。
