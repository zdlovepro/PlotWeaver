# 第一模块规格：中等粒度剧情梗概

## 1. 唯一职责

第一模块是“剧情压缩层”，不是“信息抽取层”。它把章节原文压缩成后续层级大纲
能够使用的主要剧情走向，保留目标、阻力、决定、行动、认知、局势和阶段结果中
真正发生变化的部分。

## 2. 输入与读取边界

- 输入为不可变章节文本 `ChapterDocument`；
- 全章自然段先获得唯一编号，再由一个只负责范围路由的请求划分为连续语义块；导航不生成章节梗概、不选择必写内容，标签不进入局部事实请求；
- 程序确定性检查分块从首段到末段连续、无遗漏、无重叠且顺序不变；分块不可用时不得退回随机长度的活动内容窗口；
- 每个语义块具有不重叠的所有权原文和少量邻接理解上下文；只有所有权原文可以产生本块内容和证据；
- 局部梗概模型先只提取梗概；程序随后对每个锁定 ID 分别调用作用分类和已形成变化提取；内容审校通过并锁定后，再逐个 ID 定位并逐个 ID 审校最小证据集合；
- 章级模型只能读取已审校的局部剧情段和局部边界帧，不读取原文片段或整章原文；
  边界帧在章级阶段不可改写。

## 3. 输出粒度

### 3.1 局部剧情段

每个语义块按原文实际主要推进数量输出纯梗概，不以详略设置语义硬上限；程序验收并锁定后，逐个 ID 分别补充作用和变化。内容忠实性、主要推进覆盖和分块内状态一致性通过后，再逐个 ID 独立定位和审校证据。只有情绪余波、气氛、
重复信息或不会改变后续走向的日常反应时可以输出空数组。每段只包含：

- 一个主要推进的梗概；
- 该推进的剧情作用；
- 它对目标、选择、阻力、认知、局势或阶段结果造成的变化；
- 用于回查的原文段落 ID。

同一目的下连续发生的询问、回答、动作和反应通常可以合并；不同结果不能只因发生在同一环节而被强制合并。
局部梗概通常控制在 25—90 个汉字；这一范围只用于引导生成，不作为语义质量否决条件。
只要具体信息参与事件、选择、状态变化或结果形成，保留较多细节本身不构成错误。

每个局部结果还固定带两个字符串字段：

- `opening_frame`：只有首分块非空，用一句话记录正文第一帧已成立或正在发生的主要状态；
- `ending_frame`：只有末分块非空，用一句话记录正文最后一帧形成的主要状态。

中间分块的两个字段必须为空。它们只用于防止章级压缩倒退首尾状态，不是人物状态表、
事实表或逐段边界摘要；章级解析器以它们为最终值，不接受后续模型改写。

### 3.2 章节核心节点

章节通常输出 2—6 个核心剧情节点，只有一个主要变化的短章允许 1 个，复杂章节
可扩展但不得超过 8 个。一个核心节点可以合并多个连续局部剧情段，语义分块边界
不得变成故事边界。局部剧情段是证据引用而非互斥所有权，同一局部段确实支持两个
不同变化时可以由相邻节点共同引用。
单个核心节点梗概通常控制在 25—80 个汉字，一句话章纲通常不超过 70 个汉字。

### 3.3 章节阶段

章节通常输出 1—4 个章节阶段，复杂章节可扩展但不得超过 6 个。阶段比单个物理场景更粗，
用于表达章节内部的“建立—推进—变化—收束”等连续部分，而不是逐场登记人物动作。

### 3.4 章级摘要

章级结果还包含一句话梗概、章节作用、开篇状态、结尾状态和章末未决问题。
第一模块不再单列“主要推动力”和“中心阻力”；目标或压力只有在造成实际变化时，
才进入核心剧情节点。未决问题没有依据时必须留空。

## 4. 选择标准

内容至少满足以下一项，才应成为独立剧情段或节点：

- 确立或改变目标；
- 形成会妨碍行动的真实阻力；
- 促成人物决定；
- 推动主要行动进入下一阶段；
- 揭示会改变理解或选择的信息；
- 改变局势或可选路径；
- 交付阶段结果；
- 承担理解章节走向不可缺少的过渡。

删除后不影响主要剧情理解的称谓、礼节、逐句动作、静态外貌、气氛和重复说明，
通常不需要成为独立产物；它们出现在完整推进中不构成质量错误。

## 5. 明确禁止

- 原子事实、命题、实体、人物关系、时间线、空间关系和知识图谱；
- 每段用途分类、动作账本、对话清单和物品清单；
- 改变原文的信息主体、陈述类型、语义模态、确定程度或实现状态；
- 使用针对某部作品、人物或具体剧情预先编写的判断规则替代本次输入的语义核对；
- 把作者写作目的写成故事内变化；
- 把并存道路、普通等待、好奇或家人叮嘱自动写成冲突；
- 把没有后文回应的内容直接判定为伏笔；
- 为满足结构而补写动机、心理结果、转折、悬念或未来结果。

## 6. 质量门槛

- 所有语义分块按原文顺序恰好覆盖全部章节一次；
- 全章恰有一个非空 `opening_frame` 和一个非空 `ending_frame`，且分别来自首、末分块；
- 边界帧与局部剧情段使用相同的主体、确定程度、信息来源、数量、顺序和流程状态质量门；
- 每个局部剧情段有原文依据，但不要求每段原文都产生语义条目；
- 局部和章级审校问题在进入唯一一次内容修订前都必须逐项独立复核；单次复核只判断一个既有问题，并返回候选原句、依据 ID 和核对说明，不得新增或改写问题；
- 详略程度、节点数量以及连续动作的拆分或合并方式不进入语义质量否决；这些只由输出结构契约和生成目标约束；
- 内容修订不得返回证据 ID 或章节边界字段；结构发生变化后只根据最终锁定内容生成一次证据；
- 章节通常满足 2—6 个核心节点和 1—4 个阶段，硬上限分别为 8 和 6；
- 所有局部剧情段由章级核心节点至少覆盖一次；
- 所有核心节点由章节阶段覆盖一次且仅一次；
- 章级梗概不存在无依据的确定性升级、重复事件或作者功能替代故事变化；
- 影响筛选与后续行动的全体结果保留总数和全称结论，不能降成少数具名人物示例；
- 同一主要推进跨越语义分块时仍可合并为一个章级节点；
- 章级状态终审只提交按既有 ID 替换的最小补丁，不能新增、删除、重排节点或重写完整章纲；
- 状态补丁按事务处理：应用后必须重跑完整质量门，引入新错误时拒绝提交，不污染已合格的结构审校结果；
- 人工抽读时，能看到主要走向和实质变化；内容较详细不降低忠实性与覆盖质量结论。

## 7. 后续模块分工

- 第二模块：跨章聚合事件、篇章和卷级大纲；
- 第三模块：从大纲需求反向回查原文，提取必要事实、实体、关系和状态；
- 更后续模块：作者风格、模板、生成提示词与作者 skill 蒸馏。
