# 运行手册

## 1. 当前迁移状态

新版按模块逐步接通。第一模块完成前，旧事实标注和旧图谱反推大纲产物只作为历史参考，不得当成新版章纲产物。

## 2. 输入位置

- `input/job.yaml`：当前任务入口；
- `novels/{author_id}/works/`：作者语料库；
- `config.yaml`：本地模型密钥和模型策略；
- `configs/profiles/`：短样本或整本配置。

## 3. 第一模块运行

目标命令形式：

```text
python main.py extract-synopsis \
  --author-id <作者代号> \
  --work-id <作品代号> \
  --limit 5 \
  --run-id <运行标识>
```

第一模块输出到：

```text
runs/{author_id}/{run_id}/module_01_local_synopsis/
```

正式接受前必须检查 `quality_report.json`，并抽读 `chapter_synopses.jsonl` 与对应原文，不能只看命令退出码。

## 4. 故障分类

- 服务失败：鉴权、余额、限流、超时；不进行内容修复。
- JSON失败：提示词、响应模式或格式契约问题。
- 分块失败：全章语义分块存在非法ID、遗漏、重叠或乱序。
- 梗概失败：主要推进、确定程度或造成的实质变化理解错误。
- 内容质量失败：梗概改变主体、来源、确定程度、因果、顺序或流程状态，或遗漏主要推进；内容较详细本身不算失败。
- 合并失败：局部剧情段遗漏、跨分块顺序错误或章纲补写不存在的内容。

升级模型只用于情节理解和章节合并问题。格式、ID和段落覆盖错误应优先修复提示词或程序契约。

## 5. Git 发布检查

发布前确认私有模块、语料、密钥、运行产物和作者输出没有被跟踪。`v2/`必须保留，且新版运行不得导入其中代码。
