# PlotWeaver 文档索引

本目录约束当前的“小说作者 Skill 蒸馏与受控重建”系统。文档不绑定某一位作者；作者标识只在运行时传入，并决定语料与 Skill 输出目录名。

| 文档 | 用途 | 面向读者 |
|---|---|---|
| [SRS.md](SRS.md) | 软件需求规格：系统必须做到什么、验收什么 | 产品、开发、测试 |
| [SDS.md](SDS.md) | 软件设计规格：模块、数据契约、运行流程、边界 | 开发、维护 |
| [MODEL_GUIDE.md](MODEL_GUIDE.md) | 本地模型、LoRA、SFT、DPO 与风格评测的使用说明 | 模型训练、部署 |
| [ROADMAP.md](ROADMAP.md) | 从现有 V3 到可验证作者 Skill 的实施阶段 | 项目管理、开发 |

## 当前系统边界

- 原文用于导入、带证据的标注、图谱构建、离线训练和独立评测。
- 正文生成器只接收当前段落的事实子图、已提交状态和风格程序，**不得接收整章原文、原文段落或未来章节内容**。
- 伏笔只有在后文存在可验证的回应、解释、兑现或反转时才成为正式伏笔；其余只能记为待验证线索或样本边界未验证线索。
- 一章生成后必须先产生并校验图谱补丁；补丁未提交，下一章不得开始。

## 文档状态

这组文档替代已删除的 V2 十三步流程与旧产物规格。代码实现以 `pipeline/` 和自动化测试为准；文档中的“下一版本”项表示已规划、尚未实现的能力，均会明确标注。
