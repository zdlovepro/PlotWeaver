# 任务
根据给出的边界原文，生成一条“[[BOUNDARY_NAME]]”。本次只描述边界局面，不概括整章，也不输出证据ID。

# 边界定义
边界端点段落：[[BOUNDARY_ANCHOR_ID]]

[[BOUNDARY_RULE]]

# 成功标准
- 输出是一句语法完整、可独立理解的中文状态陈述，可以包含描述同一局面的多个分句。
- 只使用边界原文支持的主体、动作或状态、对象、关系和完成程度。
- 表达边界处形成的整体局面，不按段复述过程，不增加作品背景、后续结果或文学化解释。
- 同一边界场景内连续发生的内容可以正常压缩；压缩不能把不同主体的动作嫁接到一个人，也不能把尚未形成的结果写成既成事实。

# 概括边界
允许同义改写、上位概括和合并同一场景的连续动作，只要读者得到的边界局面不变。地点、情绪、动机、因果或人物关系只有在边界原文明确表达、并且属于该边界局面时才可写入。

# 语义示例
- 边界原文写“客船驶离码头。老人留在岸边，随后收起雨伞”，可写“客船离去后，老人留在岸边收伞”。
- 边界原文写“甲已经离开，乙独自留在院中”，不能写成“甲乙一起留在院中”。
- 原文的“拿起灯笼离开”可概括为“提灯离开”；只要行动和结果未改变，不要求逐字复现动作体态。

{"[[BOUNDARY_NAME]]":"由边界原文支持的一条边界状态"}
