以下是使用 **`deepseek-v4-flash` 模型开启思考模式** 的 Python 代码示例。

---

### 1. 安装依赖
```bash
pip install openai
```

### 2. 基础非流式调用（获取推理过程 + 回答）
```python
from openai import OpenAI

client = OpenAI(
    api_key="你的DeepSeek API Key",   # https://platform.deepseek.com
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",        # Flash 快速模型
    messages=[
        {"role": "user", "content": "9.11 和 9.8 哪个大？"}
    ],
    reasoning_effort="high",          # 可选：high 或 max（low/medium 会被自动映射为 high）
    extra_body={"thinking": {"type": "enabled"}}   # 显式开启思考模式（默认其实已开启，建议保留）
)

print("最终回答：", response.choices[0].message.content)
print("思考过程：", response.choices[0].message.reasoning_content)
```

### 3. 流式调用（实时输出思考链和回答）
```python
from openai import OpenAI

client = OpenAI(api_key="你的DeepSeek API Key", base_url="https://api.deepseek.com")

stream = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "解释什么是量子纠缠"}],
    reasoning_effort="high",
    extra_body={"thinking": {"type": "enabled"}},
    stream=True
)

switched = False
print("🧠 思考过程：", end="", flush=True)
for chunk in stream:
    delta = chunk.choices[0].delta
    # 先输出推理内容
    if hasattr(delta, "reasoning_content") and delta.reasoning_content:
        print(delta.reasoning_content, end="", flush=True)
    # 正式回答开始时换行提示
    elif delta.content:
        if not switched:
            print("\n✨ 正式回答：", end="", flush=True)
            switched = True
        print(delta.content, end="", flush=True)
```

### 4. 多轮对话拼接（无工具调用时，reasoning_content 无需回传）
根据文档：两个 user 消息之间若无工具调用，中间 assistant 的 `reasoning_content` **会被 API 自动忽略**，直接 `append` 整个 message 即可。

```python
# 第一轮
messages = [{"role": "user", "content": "9.11 和 9.8 哪个大？"}]
resp1 = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=messages,
    extra_body={"thinking": {"type": "enabled"}}
)

# 直接把整个 assistant 消息加入历史（包含 reasoning_content 也无害）
messages.append(resp1.choices[0].message)

# 第二轮
messages.append({"role": "user", "content": "那 9.9 呢？"})
resp2 = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=messages,
    extra_body={"thinking": {"type": "enabled"}}
)
print(resp2.choices[0].message.content)
```

### 5. 工具调用时的注意事项
如果使用了工具（function calling），**必须** 在后续请求中将所有 `reasoning_content` 原样回传，最简单的方式同样是直接 `append` 整个响应消息：

```python
messages.append(response.choices[0].message)  # 包含 content, reasoning_content, tool_calls
```
若未回传，API 会返回 400 错误。详细工具调用示例可参考官方文档。

---

### 参数与限制速查
| 参数 | 说明 |
|------|------|
| `model` | **`deepseek-v4-flash`**（旧版 `deepseek-chat` / `deepseek-reasoner` 将于 2026‑07‑24 弃用） |
| `thinking` | 通过 `extra_body` 传入 `{"thinking": {"type": "enabled"}}`，默认即为 `enabled` |
| `reasoning_effort` | `high`（默认）或 `max`，传入 `low` / `medium` 会被自动映射为 `high` |
| **不支持的参数** | `temperature`, `top_p`, `presence_penalty`, `frequency_penalty` — 设置不报错但不生效 |
| 返回字段 | `message.content`（最终回答）, `message.reasoning_content`（思考链） |

如果你需要 **Flash 模型 + 思考模式** 的最简代码，第一个非流式示例即可开箱即用。
