# 模型实验目录规范

`experiments/` 只存放与正式流水线隔离的模型能力实验。任何为了判断模型能否完成某个单项任务而编写的脚本，都必须放在本目录下自己的子目录中，不得混入 `pipeline/`。

每个实验至少应保存：

- 可复现的输入范围与运行命令；
- 最终发送给模型的 system/user 消息；
- 模型原始返回、JSON 解析结果和调用元数据；
- 与正式模块同口径的人工对照结论；
- 明确区分模型内容错误、提示词任务耦合、程序解析错误和审校误判。

实验不得被正式模块自动调用，也不得把小说专属结论硬编码回正式提示词。实验结果只能用于验证通用任务拆分、数据契约、上下文范围和质量检测方法。
